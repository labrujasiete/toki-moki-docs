# Toki Moki — resumen visual

Página pública con el resumen de la pre-producción de **Toki Moki**: un juego móvil de mascota digital con IA,
cuarto personal isométrico 2D (el Nido) y mundo social.

- Sitio: https://labrujasiete.github.io/toki-moki-docs/
- Contenido: decisiones tomadas, formato de mundos (un Nido completo en 169 bytes), flujos, números clave y roadmap.
- La documentación detallada del proyecto es privada.

"Toki Moki" es un nombre provisional sujeto a búsqueda de marcas.
